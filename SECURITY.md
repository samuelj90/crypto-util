# Security Policy

## Supported Versions

Only the latest commit on the primary branch is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately.
Do NOT create public GitHub issues for security vulnerabilities.

Please send an email to samuelj90@gmail.com with:
1. Description of the vulnerability.
2. Steps to reproduce the issue.
3. Potential impact.

You will receive an acknowledgment within 48 hours.
